## Marking Operations by ARTEL

Пилотный локальный плагин для работы с «Честным знаком»: проверка карточек, заказов и документов, подготовка этикеток и черновиков. Версия 0.1.0 не выпускает коды, не меняет карточки и не отправляет документы.

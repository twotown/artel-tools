# Marking Operations by ARTEL · v0.1.0

Пилотный локальный плагин для «Честного знака». Установка и синтетическое демо проверены на macOS с локальным Codex. Windows и установка в конкретном клиентском аккаунте пока не проверены.

1. Скачайте и распакуйте ZIP. Откройте `Установка.md` внутри архива.
2. Для первого запуска используйте деморежим. Нужны Python 3.12 или 3.13 и доступ к локальным плагинам.
3. Для работы с реальными данными настройте доступы своего юрлица отдельно к Национальному каталогу, СУЗ и ГИС МТ. Ключи и электронная подпись не входят в архив. Не отправляйте их в чат или этот репозиторий.

Версия 0.1.0 читает и сверяет данные, готовит этикетки и черновики. Эмиссия кодов, изменение карточек и отправка документов недоступны из этого плагина.
